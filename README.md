## 📌 Огляд проєкту та інженерні цілі

Головна мета розроблюваного застосунку на базі бібліотеки React — трансформувати традиційний статичний інформаційний сайт-візитку на динамічний інтерактивний веб-сервіс самообслуговування з миттєвим розрахунком вартості споруд у реальному часі та прозорим відстеженням етапів виготовлення.

### Ключові функціональні модулі:

- 🚀 **Single Page Application (SPA):** Миттєвий відгук (<50 мс) на базі React 18, Vite 5 та Virtual DOM без повторних перезавантажень сторінок.
- 📊 **Інтерактивний Dynamic Pricing Engine (Квіз-калькулятор):** Покроковий конфігуратор на базі хука `useReducer` із вибором габаритів, породи дерева (смерека, дуб, сосна) та гарантованою знижкою -5% на монтаж.
- 🌲 **Реактивний каталог продукції:** Миттєва клієнтська фільтрація за категоріями (альтанки, будинки, лазні, садові гойдалки) та повнотекстовий пошук.
- 📹 **Особистий кабінет замовника (Client Portal):** 6-етапний степер виконання договору підряду та онлайн-трансляція з виробництва (**Live WebCam 1080p**) зі стапелів цеху ручної рубки в Закарпатті.
- 🪪 **Модуль безпечної авторизації:** Підтримка **Дія.Підпис** / Google SSO для юридичного підписання договорів, безпарольний OTP-вхід за телефоном чи Telegram-ботом, сесійні JWT-токени.
- 💾 **Збереження стану (State Resilience):** Автоматична персистентність відповідей користувача у `LocalStorage` через хук `useEffect`.

## 🎨 Дизайн-система (Biophilic Eco Theme)

Інтерфейс спроєктовано в біофільній еко-стилістиці з акцентом на природні текстури карпатського лісу:

| Токен дизайну        | Код кольору | Назва відтінку        | Призначення в UI                                       |
| :------------------- | :---------- | :-------------------- | :----------------------------------------------------- |
| `color-bg-dark`      | `#121E15`   | Dark Forest Slate     | Базовий фон сторінки та модальних вікон                |
| `color-bg-surface`   | `#1A2C1F`   | Deep Evergreen        | Фон карток каталогу, калькулятора та віджетів          |
| `color-accent-wood`  | `#C99B63`   | Carpathian Amber Gold | Акцентні CTA-кнопки, бейджі, логотип                   |
| `color-accent-dark`  | `#B0824B`   | Aged Timber Wood      | Стан наведення курсору (hover), рамки полів            |
| `color-eco-green`    | `#2ECC71`   | Emerald Leaf          | Індикатор успішних кроків, гарантії, статус «В роботі» |
| `color-text-primary` | `#F8FAFC`   | Pure Polar White      | Заголовки H1–H3, ціни, ключові ТТХ                     |

**Типографіка:** Шрифтова пара `Plus Jakarta Sans` (заголовки, кнопки дій) + `Inter` (описи та таблиці характеристик) + `Consolas` (технічні коди замовлень та таймкоди камер).

## 🚀 Встановлення та локальний запуск

```bash
# 1. Клонування репозиторію
git clone https://github.com/Maxiimilliaan/KEPYCH.ECO.ZRUB.git

# 2. Перехід у каталог проєкту
cd KEPYCH.ECO.ZRUB

# 3. Встановлення залежностей
npm install

# 4. Запуск локального сервера розробки
npm run dev

# 5. Збирання оптимізованого продакшн-білду
npm run build
```
